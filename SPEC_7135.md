# SPEC_7135: Price Amount Card with Currency Selector + Add Product Refactor

## Overview

This feature refactors and improves the **Open Prices** flow in the Smooth App (Open Food Facts). The main goals are:

1. **Embed a currency selector** directly in the proof card header (replacing the standalone currency card).
2. **Refactor the "Add Product" card** into a modular action-based architecture with a FAB (Floating Action Button) for multi-product mode.
3. **Redesign the Price Amount Card** as a sliver-based list that shows all products in a single card with quantity/sum indicators.
4. **Improve the Location Card** to display full address details and add map/edit header buttons.
5. **Introduce a barcode scanner modal** (bottom sheet) for single-barcode scanning.
6. **Improve the Category Input Page** UI with card-based layout and expandable FAB.
7. **Make `PriceAmountModel` a `ChangeNotifier`** to enable reactive sum computation.
8. Various UI polish and import cleanup across the codebase.

  - Watches `PriceModel` via `context.watch<PriceModel>()`.
  - Displays the currency full name (e.g., "Euro (€)") with a down chevron icon.
  - Uses a white `Material` pill with `BorderRadius.all(Radius.circular(16.0))`.
  - On tap, calls `PriceCurrencySelector.openSelector(context: context)`.
  - Wrapped in a `Tooltip` with localized `prices_amount_update_currency` message.
  - Uses the app's `SmoothColorsThemeExtension` for text/icon coloring based on light/dark theme.

### Files to Modify
- **`lib/pages/prices/price_proof_card.dart`**:
  - Add `trailing: const PriceCurrencyButton()` to the `SmoothCardWithRoundedHeader`.
  - Refactor `_ProofSource.process()` to no longer accept a `PriceModel` parameter; instead read it from `context.read<PriceModel>()` internally.

- **`lib/pages/prices/price_currency_selector.dart`**:
  - Extract a new `static Future<void> openSelector({required BuildContext context})` method that reads `PriceModel` from context, opens the currency selector, and sets the currency on the model.
  - Simplify the existing button's `onPressed` to call this static method.

- **`lib/pages/prices/currency_extension.dart`**:
  - Add a public `String get symbol` getter on the `CurrencyExtension` that looks up the `_symbols` map.

### Files to Remove
- **`lib/pages/prices/price_currency_card.dart`** — No longer used; the standalone currency card is replaced by the header button.

### Localization

## 2. Add Product Card Refactor (Action-Based Architecture)

### What
Replace the monolithic `PriceAddProductCard` (old, stateful, single file) with a modular architecture using a sealed `PriceAddProductAction` class and separate action implementations.

### Directory Structure
Create a new directory: `lib/pages/prices/add_product/`

### Files to Create

#### `lib/pages/prices/add_product/price_add_product_action.dart`
- Define a `sealed class PriceAddProductAction` with:
  - `String label(AppLocalizations appLocalizations)`
  - `Widget icon(BuildContext context)`
  - `Future<void> execute(BuildContext context)`
- Expose a top-level getter `List<PriceAddProductAction> get priceAddProductActions` returning the 3 actions.
- Define shared helper functions:
  - `Future<void> _addBarcodesToList(List<String> barcodes, BuildContext context)` — checks for duplicate barcodes in `PriceModel`, adds new ones as `PriceMetaProduct.unknown`, shows alert dialogs for duplicates.
  - `void _addProductToList(PriceModel, PriceMetaProduct, BuildContext)` — simply calls `priceModel.add(PriceAmountModel(product: product))`.
- Uses Dart `part` directives for the 3 action files.

#### `lib/pages/prices/add_product/actions/price_add_product_barcode_reader.dart`
- `part of '../price_add_product_action.dart'`
- Class `_PriceAddProductActionBarcodeReader extends PriceAddProductAction`
- Label: `appLocalizations.prices_barcode_reader_action`
- Icon: `Icon(Icons.barcode_reader)`
- Execute: Checks `UserPreferences` for multi-selection flag. If enabled, pushes `PriceScanPage` (with `latestScannedBarcode: null`). If not, calls `showSingleBarcodeScanner(context)` (the new modal scanner). Adds resulting barcodes to list.

#### `lib/pages/prices/add_product/actions/price_add_product_text_input.dart`
- `part of '../price_add_product_action.dart'`
- Class `_PriceAddProductActionBarcodeInput extends PriceAddProductAction`
- Label: `appLocalizations.prices_barcode_enter`
- Icon: `Icon(Icons.text_fields)`
- Execute: Shows a `SmoothAlertDialog` with a `SmoothTextFormField` for barcode input. Validates barcode length >= 8. Cleans input to digits only. On submit, adds barcode to list.
- Private helpers: `_isValidBarcode(String)`, `_getCleanBarcode(String)`.

#### `lib/pages/prices/add_product/actions/price_add_product_category.dart`
- `part of '../price_add_product_action.dart'`
- Class `_PriceAddProductActionCategoryInput extends PriceAddProductAction`
- Label: `appLocalizations.prices_category_enter`
- Icon: `icons.Ingredients()` (custom app icon, not Material)
- Execute: Pushes `PriceCategoryInputPage`, receives `PriceMetaProduct`, adds it to `PriceModel`.

#### `lib/pages/prices/add_product/price_add_product_button.dart`
- `PriceAddProductButton` — a `FloatingActionButton` (circular) displayed in multi-product mode when products already exist.
- On press, shows a `showSmoothListOfChoicesModalSheet` bottom sheet with the 3 actions (barcode reader, text input, category).
- Uses `SmoothColorsThemeExtension.secondaryVibrant` as background.
- Icon: `icons.Add.circled(color: Colors.white)`.
- Tooltip: `appLocalizations.prices_add_an_item`.

#### `lib/pages/prices/add_product/price_add_product_card.dart`
- New `PriceAddProductCard` — a simplified `StatelessWidget` (replaces the old stateful one).
- Uses `SmoothCardWithRoundedHeader` with title "Add an item".
- Renders 3 `SmoothLargeButtonWithIcon` buttons from `priceAddProductActions`.
- Shown only when `model.multipleProducts && model.length == 0` (no products added yet).

### Files to Remove
- **`lib/pages/prices/price_add_product_card.dart`** (the old 276-line monolithic file).

## 3. Price Amount Card Redesign (Sliver-Based)

### What
Convert `PriceAmountCard` from rendering a single product per card to rendering ALL products in a single sliver card, with quantity and sum indicators in the header.

### Files to Create

#### `lib/pages/prices/price_amount_card_item.dart`
- `PriceAmountCardItem` — a `StatefulWidget` that takes an `index`.
- Extracted from the old `PriceAmountCard` logic: shows product tile, price-per dropdown (for categories), promo switch, and paid/without-discount fields.
- TextEditingControllers add listeners that call `model.paidPrice = ...` and `model.priceWithoutDiscount = ...` (triggering `notifyListeners` on the model).
- Delete button uses `icons.Close.circled(size: 15.0)` with a `CircleBorder` ink splash.
- Empty promo field uses `EMPTY_WIDGET` instead of `Container()`.
- `SwitchListTile` has `contentPadding: EdgeInsetsDirectional.zero`.

#### `lib/pages/prices/price_amount_quantity.dart`
- `PriceAmountQuantity` — shows the count of items as a white pill badge with `icons.Ingredients.basket()` icon and the count number.
- Watches `PriceModel` for `model.length`.

#### `lib/pages/prices/price_amount_sum.dart`
- `PriceAmountSum` — shows the total paid price sum as a white pill badge with `icons.Currency()` icon.
- Uses `MultipleChangeNotifierBuilder<PriceAmountModel>` (new helper) to listen to ALL `PriceAmountModel` instances.
- Formats using `NumberFormat.simpleCurrency(locale: ..., name: model.currency.name)`.
- Calculates total by summing `double.tryParse(model.paidPrice.replaceAll(',', '.'))` for each model.

### Files to Modify

#### `lib/pages/prices/price_amount_card.dart`
- Complete rewrite: `PriceAmountCard` becomes a `StatelessWidget`.
- No longer takes an `index` parameter.
- Uses `SliverCardWithRoundedHeader` (not `SmoothCardWithRoundedHeader`) — this is a sliver variant.
- Title: `appLocalizations.prices_amount_subtitle` (no index suffix).
- Leading: `Icon(Icons.calculate_rounded)`.
- Trailing (only when `model.multipleProducts`): a `Row` with `PriceAmountQuantity` and `PriceAmountSum`.
- Content: `ListView.separated` with `shrinkWrap: true`, `NeverScrollableScrollPhysics`, items are `PriceAmountCardItem(index: index)` separated by `Divider`.
- Content padding: only horizontal `SMALL_SPACE`, no vertical padding.

#### `lib/pages/prices/price_amount_model.dart`
- Change `PriceAmountModel` to `extends ChangeNotifier`.
- Add `notifyListeners()` calls in the setters for `paidPrice`, `priceWithoutDiscount`, and `promo`.

#### `lib/pages/prices/price_amount_field.dart`
- Add a `suffixIcon` to the text field showing the currency symbol.
  - Uses `context.watch<PriceModel>().currency.symbol`.
  - Wrapped in `SizedBox(height: kMinInteractiveDimension, width: 10.0)` with `Center`.
  - Bold text style.
- Add `maxLines: 1`.

#### `lib/pages/prices/price_model.dart`
- In `removeAt()`: call `_priceAmountModels[index].dispose()` before removing.
- Add `List<PriceAmountModel> get priceAmountModels => _priceAmountModels`.
- Override `dispose()` to dispose all `PriceAmountModel` instances, then call `super.dispose()`.

## 12. Key Architectural Decisions

1. **Sealed class pattern** for add-product actions — ensures exhaustive handling and clean separation of concerns.
2. **`part`/`part of` directives** — the action implementations are `part` files of `price_add_product_action.dart`, sharing private helpers.
3. **`PriceAmountModel` as `ChangeNotifier`** — enables the sum widget to reactively update when individual price fields change, via `MultipleChangeNotifierBuilder`.
4. **Sliver-based amount card** — `SliverCardWithRoundedHeader` integrates into `CustomScrollView` for smoother scrolling with many products.
5. **Dual FAB pattern** — center FAB for adding products + end FAB for submitting, both in a `Stack`.
6. **`rootNavigator: true`** — used when pushing the price add page to ensure it appears above tab navigation.
