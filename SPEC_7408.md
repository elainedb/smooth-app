# SPEC_7408: Add Discount Type to Price Entries

## Overview

Add support for a `discountType` field in the price entry workflow. When a user marks a price as discounted (promo), they should be able to select a discount type from a dropdown. The discount type should also be displayed in read-only mode when viewing existing discounted prices. The field must be persisted through background task serialization/deserialization and sent to the Open Prices API.

This feature uses the `DiscountType` enum from the `openfoodfacts` Dart package (`package:openfoodfacts/openfoodfacts.dart`).

**Deserialization (`fromJson`):**
- Deserialize `discountTypes` using a new static method `_normalizeDiscountTypes` that takes the raw JSON value and an expected length (derived from barcode count: `1` if `_jsonTagBarcode` key exists, otherwise length of `_jsonTagBarcodes` list).

**`_normalizeDiscountTypes` static method:**
```dart
static List<String> _normalizeDiscountTypes(
  final List<String?>? input,
  final int expectedLength,
) {
  final List<String> result = List<String>.filled(expectedLength, '');
  if (input != null) {
    for (int i = 0; i < input.length && i < expectedLength; i++) {
      result[i] = input[i] ?? '';
    }
  }
  return result;
}
```
This handles cases where the discount types list may be shorter than barcodes or contain nulls.

**Serialization (`toJson`):**
- Add `result[_jsonTagDiscountTypes] = discountTypes;`

**Upload logic (in the method that builds `Price` objects for the API):**
- When iterating over prices to build API `Price` objects, determine the `DiscountType?`:
  - If `priceIsDiscounted` is true: `DiscountType.fromOffTag(discountTypes[i])` (may return `null` if tag is empty/invalid).
  - If not discounted: `null`.
- Set `..discountType = discountType` on the `Price` object being constructed.
- Also pass `discountTypes: <String>[discountTypes[i]]` when recursively calling `addTask` for single-barcode splitting.

## Data Flow Summary

```
User UI (PriceAmountCard)
  → PriceAmountModel.discountType (DiscountType?)
  → PriceModel.addTask() converts to offTag string
  → BackgroundTaskAddPrice / BackgroundTaskAddOtherPrice stores as List<String>
  → BackgroundTaskPrice.toJson() serializes to JSON
  → BackgroundTaskPrice.fromJson() deserializes with normalization
  → BackgroundTaskPrice upload method converts back to DiscountType? via fromOffTag
  → Sets Price.discountType on the API object
```

## Key Implementation Notes

1. **The `DiscountType` enum comes from `package:openfoodfacts/openfoodfacts.dart`** — it has an `offTag` string property and a `fromOffTag` static constructor. Do not redefine it.
2. **The discount type dropdown should only appear when the price is marked as discounted** (`model.promo == true`).
3. **Discount type is optional** — a user can mark a price as discounted without specifying a discount type. The empty string `''` is used as the "no type selected" sentinel in the `List<String>` serialization layer.
4. **Normalization on deserialization** is critical for backward compatibility — existing tasks in the queue won't have `discountTypes` in their JSON, so `_normalizeDiscountTypes` must handle `null` input gracefully by returning a list of empty strings.
5. **`app_localizations.dart` is auto-generated** — run `flutter gen-l10n` after modifying `app_en.arb` to regenerate it.
6. **Follow the existing code style**: use `super.discountTypes` syntax in constructors, use `final` parameters, use the same JSON tag naming pattern (`_jsonTag*` private static constants).
