# SPEC_7408v2: Add Discount Type to Price Entries

## Goal

When a user marks a price as discounted, allow them to select a discount type from a dropdown. Display the discount type as read-only when viewing existing discounted prices. Persist the selection through background task serialization and send it to the Open Prices API.

## Requirements

1. **Discount type selection**: Add a `DiscountType` dropdown (using the `DiscountType` enum from `package:openfoodfacts/openfoodfacts.dart`) to the price entry form. The dropdown should only be visible when the price is marked as discounted.

2. **Read-only display**: Show the discount type as a read-only text field when viewing existing discounted prices.

3. **Localization**: Add English localization strings for the label "Discount type" and all `DiscountType` enum values: Quantity discount, Sale, Seasonal, Loyalty program, Expires soon, Pick it yourself, Second hand, Other.

4. **Background task persistence**: Add `discountTypes` (as `List<String>` using `DiscountType.offTag`) to the background task data model. Normalize the list length to match barcodes count on deserialization, defaulting to empty strings for missing/null entries (backward compatibility).

5. **API upload**: Convert the stored string back to `DiscountType?` via `DiscountType.fromOffTag` and set it on the `Price` object before upload. Only set it when the price is discounted.

## Key Constraints

- `DiscountType` enum, its `offTag` property, and `fromOffTag` constructor come from `package:openfoodfacts/openfoodfacts.dart` — do not redefine them.
- Discount type is optional — a discounted price does not require a discount type. Empty string `''` is the "none selected" sentinel.
- `app_localizations.dart` is auto-generated — only edit `app_en.arb`, then run `flutter gen-l10n`.
